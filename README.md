# 🧮 Lógica de Programación 3: Cálculo de Factorial

##  Descripción
Programa desarrollado en JavaScript que solicita un número al usuario, valida los datos ingresados y calcula su factorial mediante un ciclo `for`.

##  Objetivo
Practicar el uso de variables, ciclos y validaciones para resolver un problema matemático mediante programación.

##  Tecnologías
- JavaScript
- Node.js
- Visual Studio Code

##  Funcionamiento
El programa solicita un número entero no negativo. Si el dato es incorrecto, vuelve a solicitarlo. Cuando el número es válido, calcula su factorial y muestra el resultado en la consola.

##  Ejemplos de resultados
- Factorial de 5: `120`
- Factorial de 6: `720`
- Factorial de 3: `6`
- Factorial de 0: `1`

## ▶ Ejecución
Instalar la dependencia necesaria:

```bash
npm install prompt-sync
```

Ejecutar el programa:

```bash
node factorial.js
```

## 📚 Aprendizajes
- Declaración de variables.
- Entrada y validación de datos.
- Uso de ciclos `while` y `for`.
- Operaciones matemáticas.
- Impresión de resultados con `console.log()`.
